## Architecture (new `src/game/`, boot routes desktop to it)
- `main.js`: menus → session → job → loop. Reuses `tv/renderer.js` (Renderer), `tv/house.js` (House: devices, power, patches, wifi heat, cones; call `house.load(id, { fpp: true })`, `cutaway(..., "none")` in FPP), `tv/hud.js` styles for job card/checklist/toasts/achievements/review, `tv/audio.js`, `tv/director.js` for the Tab map, `tv/client.js` Walker for the handover client.
- `session.js`: host = room creator, runs `reduce()` and broadcasts snapshots exactly like `tv/main.js` (onMsg/sendState/beginJob/handover/autosave). Clients send `{t:'act'}`. Everybody renders from the snapshot. Player poses streamed ~10 Hz `{t:'pose', p:[x,y,z], yaw, pitch, tool}` → avatars (`buildPlayer`). Net layer `src/net/*` unchanged (WebRTC + RTDB signaling + relay). Public rooms: RTDB node `instalator/lobby/$code` = { name, host, building, players, public, at } refreshed every 20 s; list query filters fresh public ones. Join by code.
- `player.js`: pointer lock, yaw/pitch, WASD (Shift sprint, Space small jump), radius 0.28 m. Horizontal collision: per-floor wall segments from `data.walls` split at passable openings (doors/gates/arches, sill < 0.1) + `obstacles` OBB polygons (skip `what === 'stairs'`) overlapping body height. Ground: BVH raycast down (three-mesh-bvh 0.9.1 in the importmap) from y+0.4 against walkable building meshes (exclude walls, ceilings, roof, instanced meshes), take highest hit with normal.y > 0.6; gravity otherwise. Floor index from y. Head bob.
- `interact.js`: hotbar item (inventory) → candidate mounts valid for that item within 3 m, pick the one nearest the crosshair with line of sight; translucent ghost + prompt. Hold LMB to install (style durations drill 1.0 s, screw 0.8 s, peel 0.5 s, tap 0.2 s) with hands animation, then `{a:'install', id, mount, style}`; cameras auto-aim along the player's yaw. Strips: target strip path. Tablet: target tablet spots → `tabletSpot` + `tabletMount`. E on panel / rack / media box → station mode. E on mounted tablet → tablet window. E on installed device → info card (uninstall, aim).
- `station.js`: camera tweens to the close-up framing (`house.focusPoint`), cursor free. Panel: click breakers to flip, drag across a row to sweep, right-click to label, DIN module from hotbar → click free slot. Rack: drag port to port (HTML hit targets projected from `house.portWorld`), mount rack gear from hotbar onto free U slots, shelf items on shelves, guide card with netStep (Podłącz / Podłącz wszystko / Napraw / Zwróć / Do rozdzielnicy), UniFi adoption list. Esc or E leaves.
- UI (`css/game.css`): crosshair, hotbar (1–9, wheel, thumbnails from `assets/thumbs`), prompt line, checklist + client card (TV HUD style, larger), turn bar (whose turn, G = end turn), toasts/achievements, shop window (B), client list (L), tablet window, pause/menu (Esc), map (Tab). Non-active player: free walk, V = follow the active player's view, F = ping.
- Handover: H (host or active) calls the client; client walker walks through, speech bubbles, then review protocol (existing).
